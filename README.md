# Pulse-Music


## Overview

Pulse Music is a responsive music web application created for the MTM6302 Final Project.

The application allows users to browse songs, search music, play audio, create playlists, and save their preferences using Local Storage. It was built using HTML, CSS, and Vanilla JavaScript.

---

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- JSON
- Fetch API
- Local Storage
- HTML Audio API

No JavaScript frameworks or libraries were used.

---

## Features

- Browse songs
- Search by title, artist, album, or genre
- Filter songs by genre
- Play, pause, next, and previous controls
- Volume control
- Like songs
- Create playlists
- Save playlists and liked songs using Local Storage
- Responsive design for desktop and mobile
- Load song data from a JSON file using Fetch API

---

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click on **index.html**.
5. Select **Open with Live Server**.
